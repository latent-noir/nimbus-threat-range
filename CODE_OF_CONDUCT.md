#  Code of Conduct

> *"In cyberspace, trust is earned — never assumed."*

## The Pact

This project exists at the intersection of **security research and education**. We operate with the same discipline we expect in cybersecurity: **integrity, respect, and responsible behavior**.

We pledge to make participation in this community a harassment-free experience for everyone, regardless of background, identity, or experience level.

## Standards

###  Expected

- Welcoming and inclusive language
- Respectful disagreement and constructive criticism
- Focusing on what strengthens the project and community
- Responsible disclosure of vulnerabilities
- Helping others learn and grow

###  Unacceptable

- Harassment, trolling, or personal attacks
- Sexualized language, imagery, or unwanted advances
- Publishing private information without consent
- Using this project for unauthorized testing against real systems
- Any conduct inappropriate in a professional setting

## Scope

This Code of Conduct applies in all project spaces — issues, pull requests, discussions, and any public representation of the community.

## Enforcement

Report unacceptable behavior to the project maintainers. All reports will be reviewed and investigated promptly and fairly. Maintainers are obligated to respect the privacy of the reporter.
